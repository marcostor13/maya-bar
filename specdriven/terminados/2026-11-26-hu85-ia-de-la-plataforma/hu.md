# HU85 — IA de la plataforma gratis para todas las empresas

**Como** dueño de Maya CRM (superadministrador), **quiero** conectar una cuenta de IA
de la plataforma (proveedor, API key y modelo) **para que** todas las empresas que no
tengan su propia API key usen la IA gratis, solo con el modelo que yo fije.

Pedido del usuario (2026-11-26): "hagamos que puedan tener una cuenta de IA conectada
para todos gratis, en la cuenta de super administrador tendría que configurarla, y que
con eso los usuarios puedan tener esa api por defecto, pero solo al modelo que yo setee".

Decisiones del usuario:
- "Gratis" = no descuenta créditos de IA; el consumo se sigue registrando por empresa.
- Una empresa con API key propia sigue eligiendo libremente proveedor y modelo.
