# HU80 — Páginas de funciones (SEO/GEO)

Como visitante que busca una herramienta concreta ("CRM para WhatsApp", "chatbot
con IA para WhatsApp"…), quiero una página clara de esa función con definición,
cómo funciona, límites por plan y preguntas frecuentes, para decidir si Maya me sirve.
Páginas: `/crm-whatsapp`, `/agentes-ia-whatsapp`, `/campanas-whatsapp`,
`/formularios`, `/eventos`, `/bandeja-unificada`. Solo datos verificables del
producto (catálogo de planes, funciones reales). Plan SEO/GEO, fase 2.
